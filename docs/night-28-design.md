# 夜タイプ診断 V6：28問の試作

ユーザーの「質問数も判断を任せる」という指示に基づく変更。2026-09-13。

## 決定

- 7つの視点を残し、4問ずつ計28問。各視点で正方向2問・逆方向2問。軸を交互に提示する。
- 28問は暫定の製品判断。十分な信頼性が実証された質問数ではない。
- 35問版の5素質・4オーラのシグネチャと20タイプ名を保持。定数は添付ファイルから抽出し、SHA-256を `lib/night-signatures.json` に記録。
- 質問文を更新したため、旧版の合成データの復元率や出現率を継承しない。
- G軸は「感情との距離」。感情労働の深層演技／表層演技を厳密に測定する尺度とは称さない。他の軸も既存の心理尺度として妥当性を主張しない。

## 採点

回答は -3〜3。分からない場面は null とし、0点の中間回答と区別する。逆方向の項目を反転し、軸ごとの有効回答平均を3で割る。全問同意でも全問否定でも、各軸が正逆2問のため平均は0になる。回答の癖を完全に補正できるという意味ではない。

タイプは正規化した元のシグネチャへの内積を用いる。5素質と4オーラのスコアの和で候補を比較。完全同点はキー順で安定して選ぶが、全軸の最大絶対値が0.17未満の場合はタイプを確定しない。いずれかの軸の有効回答が3未満なら材料不足とする。次点との差が0.12未満なら近いタイプも提示する。これらのしきい値は暫定の運用ルールであり、統計的な信頼区間ではない。

配合は軸スコアの内積に係数1.8のsoftmaxを適用し、最大剰余法で合計100になる整数にする。的中度・人口比・能力の割合ではない。元実装とは軸のスケールとsoftmaxを変更したため、旧配合との一致を目標にしない。

## 結果文

最も強い傾向に基づく導入、2軸の組み合わせ8種、席・関係・動機の説明、保存用4項目。説明の根拠になった回答を表示する。場面で回答が分かれた軸も注記する。追加の診断質問は要求しない。

## 保存と共有

初期設定は回答を保存しない。本人が選択した場合のみ、このブラウザに途中の回答と結果を保存。削除ボタンを用意。サーバー収集、外部AI、連絡先入力は無し。

共有画像はブラウザで1080×1920 PNGを生成。共有リンクは20タイプの静的紹介ページで、回答を含まない。個人別の結果URLではない。年齢ゲートは18歳以上という利用条件の自己申告であり、本人確認機能ではない。

## 検証の次の段階

質問数を減らした尺度は開発と検証の対象になる。例えばSoto & John (2017)はBFI-2の30問・15問の短縮版を検証し、測る粒度による制約も報告している。これはNOBLEの28問を正当化する直接証拠ではない。

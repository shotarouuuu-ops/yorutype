# 夜職診断 / Yoru Type

Next.js + TypeScript + Tailwind CSS で実装した、スマホファーストの夜職タイプ診断アプリです。

## Features

- SEO title / h1 対応
- OGP metadata
- `sitemap.xml` / `robots.txt` 自動生成
- 診断開始、質問回答、結果表示
- SNSシェア対応
- Vercel公開可能なNext.js構成

## Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run typecheck
npm run build
```
